# Afterform® — Make the next thing real

An expressive, responsive portfolio website for a fictional independent creative-technology office.

Stack: semantic HTML, CSS, and vanilla JavaScript. No bundler or API keys.

## Run locally
Open index.html, or run python -m http.server 8000 and visit http://localhost:8000.

## Features
- Responsive navigation and filterable concept-work gallery
- CSS 3D orb with layered depth, orbital motion, and bounded pointer parallax
- Project panels with subtle perspective tilt on pointer devices
- Scroll-triggered reveals, staggered filter transitions, and scroll progress
- Pause/resume motion control, keyboard focus, semantic landmarks, reduced-motion support
- No Three.js bundle required for this design
